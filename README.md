# DarsFlow

DarsFlow is a validation prototype for small Quran, Arabic and Islamic studies academies. It explores how a short teacher observation can become a reviewed parent update, teacher handover, and structured progress record.

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
- ESLint

## Prerequisite

Node.js 20.9 or newer.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Verification

```bash
npm run lint
npm run build
```

## Current exclusions

- No real student data
- No AI integration
- No database
- No authentication
- No WhatsApp integration
